=== lesson bio_seq
title: Seq objects and genetic codes
minutes: 9
--- text
You have written reverse complements and translations by hand. That was worth doing once — now meet **Biopython**, the library most bioinformaticians use for this every day. It is installed in Python Lab.

A `Seq` behaves like a string (you can `len()` it, slice it, loop over it) but knows biology:

```python
from Bio.Seq import Seq

dna = Seq("ATGGCCATTGTAATGGGCCGCTGA")
print(dna.complement())
print(dna.reverse_complement())
print(dna.transcribe())        # DNA -> mRNA (T becomes U)
print(dna.translate())         # protein; '*' marks a stop
```

`translate()` has useful options:

- `to_stop=True` stops at the first stop codon (and leaves the `*` out)
- `table=…` picks the **genetic code**: NCBI numbers them, and `1` (the standard code) is the default

| Table | Used by | Difference from the standard code |
|---|---|---|
| 1 | most nuclear genes | — |
| 2 | vertebrate mitochondria | `AGA`/`AGG` stop, `ATA` = Met, `TGA` = Trp |
| 4 | *Mycoplasma*, *Spiroplasma* | `TGA` = Trp |
| 11 | bacteria, archaea, plastids | same codons as 1 (different start codons) |

GC content comes from `Bio.SeqUtils`:

```python
from Bio.SeqUtils import gc_fraction
print(gc_fraction("ATGGCC"))   # 0.6667 -> a fraction, multiply by 100 for %
```

> **In the lab:** translating a *Mycoplasma* gene with the standard code gives a protein that "stops" in the middle at every `TGA`. Picking the right table is the difference between a broken ORF and the real protein.
--- example
from Bio.Seq import Seq
from Bio.SeqUtils import gc_fraction

dna = Seq("ATGGCCATTGTAATGGGCCGCTGA")
print("revcomp :", dna.reverse_complement())
print("mRNA    :", dna.transcribe())
print("protein :", dna.translate())
print("to stop :", dna.translate(to_stop=True))
print(f"GC      : {gc_fraction(dna) * 100:.1f} %")

=== lesson seqio_fasta
title: Reading and writing FASTA with SeqIO
minutes: 9
--- text
In chapter 7 you wrote a FASTA parser yourself. `Bio.SeqIO` does it in one line, for FASTA, FASTQ, GenBank and about 40 other formats:

```python
from Bio import SeqIO

for record in SeqIO.parse("sequences.fasta", "fasta"):
    print(record.id, len(record.seq))
```

Each **record** (a `SeqRecord`) has:

| Attribute | What it is |
|---|---|
| `record.id` | the first word of the header (`lmnA_frag`) |
| `record.description` | the whole header line |
| `record.seq` | the sequence, as a `Seq` (so `.translate()` etc. work) |

`SeqIO.parse` reads **many** records; `SeqIO.read` reads a file that holds **exactly one**.

Writing is just as short: give `SeqIO.write` a list of records, a file name and a format.

```python
long_ones = [r for r in SeqIO.parse("sequences.fasta", "fasta") if len(r.seq) > 500]
SeqIO.write(long_ones, "long.fasta", "fasta")
```

> **In the lab:** the same three lines convert formats — `SeqIO.parse(..., "fastq")` then `SeqIO.write(..., "fasta")` turns sequencing reads into a FASTA file.
--- example
from Bio import SeqIO

for record in SeqIO.parse("sequences.fasta", "fasta"):
    protein = record.seq.translate(to_stop=True)
    print(f"{record.id:<10} {len(record.seq):>4} bp  {len(protein):>4} aa   {record.description}")

=== lesson genbank_features
title: GenBank files and their features
minutes: 12
--- text
A **GenBank** file is a sequence plus its annotation: which stretch is a promoter, a CDS, a primer site. Plasmid maps from Addgene and SnapGene exports use the same format. `pLAB1.gb` in your workspace is a small synthetic expression plasmid — open it in the Playground's Files list to see what the text looks like.

```python
from Bio import SeqIO

plasmid = SeqIO.read("pLAB1.gb", "genbank")
print(plasmid.description, len(plasmid), "bp")
print(plasmid.annotations["topology"])        # circular
```

`plasmid.features` is a list of **features**. Each one has:

| Attribute | Example |
|---|---|
| `feature.type` | `"CDS"`, `"promoter"`, `"RBS"` |
| `feature.location.start` / `.end` | `121`, `841` — **0-based**, end not included (like slicing) |
| `feature.location.strand` | `1` (forward) or `-1` (reverse) |
| `feature.qualifiers` | a dict of **lists**: `feature.qualifiers["gene"][0]` → `"gfpL"` |

The best part: `feature.extract(plasmid.seq)` cuts out the feature's sequence **and reverse-complements it if it is on the minus strand**, so you can translate it directly.

```python
for f in plasmid.features:
    if f.type == "CDS":
        cds = f.extract(plasmid.seq)
        print(f.qualifiers["gene"][0], cds.translate(table=11, to_stop=True)[:20])
```

> **In the lab:** GenBank shows positions counted from 1 (`122..841`); Biopython counts from 0 (`121`). When you report a position to a person, add 1 to `start`.
--- example
from Bio import SeqIO

plasmid = SeqIO.read("pLAB1.gb", "genbank")

=== lesson entrez_search
title: Searching NCBI with Entrez
minutes: 12
--- text
**Entrez** is NCBI's search system (the same one behind the PubMed and Nucleotide web pages). `Bio.Entrez` lets a program search and download records, so you can fetch 200 sequences without 200 clicks.

The two calls you will use most:

| Call | Does | Gives back |
|---|---|---|
| `Entrez.esearch(db=..., term=..., retmax=...)` | searches a database | record **IDs** |
| `Entrez.efetch(db=..., id=..., rettype="gb", retmode="text")` | downloads records | GenBank / FASTA text |

A search term uses the same **field tags** as the NCBI website: `LMNA[Gene]`, `"Homo sapiens"[Organism]`, `refseq[filter]`, combined with `AND`, `OR`, `NOT`.

This is what a real search and download look like. It needs internet; press **Try it** to run it live (please put your own e-mail address in — NCBI asks every program to say who is calling):

```python
from Bio import Entrez, SeqIO

Entrez.email = "your.name@university.edu"
handle = Entrez.esearch(db="nucleotide", term='LMNA[Gene] AND "Homo sapiens"[Organism] AND refseq[filter]', retmax=3)
result = Entrez.read(handle)
print(result["Count"], "records; first IDs:", result["IdList"])

handle = Entrez.efetch(db="nucleotide", id=result["IdList"][0], rettype="gb", retmode="text")
record = SeqIO.read(handle, "genbank")
print(record.id, record.description, len(record), "bp")
```

Rules of the road: set `Entrez.email`, make **no more than 3 requests per second** (10 with a free NCBI API key in `Entrez.api_key`), and download large sets in batches.

`Entrez.read` turns NCBI's XML reply into Python dicts and lists. So that this lesson works offline, your workspace has a **saved reply**, `esearch_lmna.xml` — real NCBI layout, placeholder IDs.

> **In the lab:** a 10-line script that pulls every RefSeq lamin transcript, or every paper on a gene since 2020, saves an afternoon — and it can be re-run next month with one click.
--- example

=== lesson align_sanger
title: Checking a clone: aligning a Sanger read
minutes: 14
--- text
You sequenced colony 7 to check your GFP construct. Is the insert correct? Line the read up against the reference and look for differences — that is a **pairwise alignment**.

```python
from Bio import Align

aligner = Align.PairwiseAligner()
aligner.mode = "local"            # the read covers only part of the gene
aligner.match_score = 2
aligner.mismatch_score = -3
aligner.open_gap_score = -5
aligner.extend_gap_score = -2

alignment = aligner.align(reference, read)[0]   # the best alignment
print(alignment)
```

`print(alignment)` draws it with `|` for matches and `.` for mismatches. To work with it in code, `alignment.aligned` gives the **matching blocks** as pairs of coordinates:

```python
for (r_start, r_end), (q_start, q_end) in zip(*alignment.aligned):
    # reference[r_start:r_end] lines up with read[q_start:q_end]
    ...
```

Inside a block, compare the two strings letter by letter to find substitutions. Between blocks are gaps (insertions or deletions).

Mutations are written as **reference base, position, new base**, counting from 1: `G181A`.

> **In the lab:** this is the core of every "verify my clone" tool. Trim the low-quality ends of the read first (the FASTQ quality-filter project) — most "mutations" in raw Sanger reads are just noise at the ends.
--- example
from Bio import Align
from Bio.Seq import Seq

reference = Seq("ATGGCTAGCAAAGGAGAAGAACTTTTCACT")
read      = Seq(     "TAGCAAAGGTGAAGAACTTTT")        # one change, ends trimmed

aligner = Align.PairwiseAligner()
aligner.mode = "local"
aligner.match_score, aligner.mismatch_score = 2, -3
aligner.open_gap_score, aligner.extend_gap_score = -5, -2
alignment = aligner.align(reference, read)[0]
print(alignment)

for (r0, r1), (q0, q1) in zip(*alignment.aligned):
    for i in range(r1 - r0):
        if reference[r0 + i] != read[q0 + i]:
            print(f"{reference[r0 + i]}{r0 + i + 1}{read[q0 + i]}")

--- hint
`reference = feature.extract(plasmid.seq)` for the CDS whose `qualifiers["gene"][0] == "gfpL"`. Then `alignment = aligner.align(reference, read)[0]`.
--- hint
`for (r0, r1), (q0, q1) in zip(*alignment.aligned):` then `for i in range(r1 - r0):` compare `reference[r0 + i]` with `read[q0 + i]`. The 1-based position is `r0 + i + 1`.
--- hint
For a 0-based position `pos`: the codon index is `pos // 3`, its bases are `reference[c*3:c*3+3]`, and the changed base sits at `pos % 3` inside it.
--- solution
from Bio import Align, SeqIO

plasmid = SeqIO.read("pLAB1.gb", "genbank")
read = SeqIO.read("sanger_read.fasta", "fasta").seq
gfp = [f for f in plasmid.features if f.type == "CDS" and f.qualifiers["gene"][0] == "gfpL"][0]
reference = gfp.extract(plasmid.seq)

aligner = Align.PairwiseAligner()
aligner.mode = "local"
aligner.match_score, aligner.mismatch_score = 2, -3
aligner.open_gap_score, aligner.extend_gap_score = -5, -2
alignment = aligner.align(reference, read)[0]

mutations, protein_changes = [], []
for (r0, r1), (q0, q1) in zip(*alignment.aligned):
    for i in range(r1 - r0):
        if reference[r0 + i] != read[q0 + i]:
            pos = r0 + i
            mutations.append(f"{reference[pos]}{pos + 1}{read[q0 + i]}")
            c = pos // 3
            old = reference[c * 3:c * 3 + 3]
            new = old[:pos % 3] + read[q0 + i] + old[pos % 3 + 1:]
            protein_changes.append(f"{old.translate(table=11)}{c + 1}{new.translate(table=11)}")

print(mutations)
print(protein_changes)
--- explain
Aligning against the CDS (not the whole plasmid) makes every position a CDS position, so `pos // 3` is directly the codon number. The local mode lets a read that covers only the middle of the gene align without being penalised for the missing ends.
